## Pourquoi

Ces différentes étapes ont été réalisées afin de préparer l'environnement de développement et de s'assurer que tous les outils nécessaires au projet fonctionnent correctement.

L'installation de VS Code, PlatformIO et Teleplot permet de programmer le microcontrôleur, de téléverser le code et de visualiser les données reçues.

Le premier programme avec le clignotement d'une LED permet de vérifier que la communication entre l'ordinateur et le microcontrôleur fonctionne correctement et que le programme est bien exécuté.

Extrait de code

Le programme suivant permet de faire clignoter la LED intégrée à la carte XIAO. La LED s'allume pendant 500 ms puis s'éteint pendant 500 ms.

```cpp
#include <Arduino.h>

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, LOW);
  delay(500);
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500);
}
```
