### 💻 Code du joystick

{: .code-example }
```cpp
// Configuration des broches
#define PIN_JOYSTICK_X       1
#define PIN_JOYSTICK_Y       3
#define PIN_JOYSTICK_SELECT  5

// Initialisation
void setup() {

    Serial.begin(115200);

    pinMode(PIN_JOYSTICK_X, INPUT);
    pinMode(PIN_JOYSTICK_Y, INPUT);
    pinMode(PIN_JOYSTICK_SELECT, INPUT_PULLDOWN);

    analogReadResolution(12);

    Serial.println();
    Serial.println("================================");
    Serial.println("       RETROCORE - JOYSTICK     ");
    Serial.println("================================");
    Serial.println("Initialisation terminee !");
}

// Boucle principale
void loop() {

    int x = analogRead(PIN_JOYSTICK_X);
    int y = analogRead(PIN_JOYSTICK_Y);
    int select = digitalRead(PIN_JOYSTICK_SELECT);

    Serial.print("> X : ");
    Serial.println(x);

    Serial.print("> Y : ");
    Serial.println(y);

    Serial.print("> SELECT : ");
    Serial.println(select);

    Serial.println("-------------------------------");

    delay(100);
}
```

## Pourquoi

Ces essais permettent de vérifier le bon fonctionnement des composants avant leur intégration dans la console.

Le test du joystick est particulièrement important puisqu'il constituera un élément essentiel pour contrôler les déplacements et les interactions dans les jeux.

La programmation permet également de vérifier que le microcontrôleur reçoit correctement les informations envoyées par les différents composants.

Le buzzer a également été testé afin de vérifier la possibilité d'ajouter des retours sonores dans la console.
